## About

Ticket Tool is a hosted support system for Discord servers. Members open tickets from a panel or a slash command, staff work them in a private channel or from the web dashboard, and every ticket is logged and transcribed.

It covers what a busy server needs past a plain support channel: ticket categories with their own permissions and messages, automation rules, a visual flow builder for intake and routing, a knowledge base, SLA and CSAT tracking, and a REST API.

[ticket-tool.app](https://ticket-tool.app) · [Dashboard](https://dash.ticket-tool.app) · [Documentation](https://ticket-tool.app/docs)

## Features

| Feature | What it does |
| --- | --- |
| Ticket categories | Separate ticket types, each with its own permissions, forms, welcome and close messages, and logging. |
| Custom panels | Button, dropdown, and command-driven panels, configured in the dashboard and deployed to any channel. |
| Support flows | Visual flow builder for intake, routing, and follow-up, with forms, conditions, loops, sub-flows, and API calls. |
| Automation rules | Trigger-based and scheduled rules that act on tickets, messages, and inactivity without building a flow. |
| Web dashboard | Read and reply to tickets from the browser, with canned replies and full ticket history. |
| Transcripts | Searchable, exportable records of every ticket, with configurable retention. |
| Knowledge base | Internal and public articles with semantic search, plus a hosted public portal. |
| Analytics | Volume, team performance, SLA breaches, CSAT, cohorts, and leaderboards. |
| AI Assist | Suggested and automatic replies, classification, routing, and summarisation, grounded in your knowledge base. |
| Integrations and API | Inbound webhook triggers, outbound webhooks, and a public REST API. |
| Localisation | Translate bot-facing text so tickets read in your community's language. |
| Notifications | Web push, email, SMS, and Discord pings, configurable per user. |

Plans run from Free through Community, Pro, Team, and Enterprise. The [pricing page](https://ticket-tool.app/#pricing) lists what each tier includes.

## Getting started

1. [Add the bot](https://discord.com/oauth2/authorize?client_id=1506999581722804274) to your server. You need Administrator or Manage Server permission.
2. Run `/setup` in Discord. The wizard asks for a staff role, a Discord category for ticket channels, a channel for the panel, and your first ticket category.
3. Click the button on the posted panel to open a test ticket and check that staff can see it.

To set it up in the browser instead, build the category and panel in the [dashboard](https://dash.ticket-tool.app), then run `/setup-panel` in Discord to post it.

Full walkthrough: [Quick Start](https://ticket-tool.app/docs/getting-started/quick-start).
